# ByClick — демонстрационный маркетплейс

Оригинальный демонстрационный макет маркетплейса на **HTML5 + SCSS (BEM)** со сборкой **Vite**.
Сделан с нуля: собственные тексты, палитра, логотип и SVG-иллюстрации. Без внешних трекеров,
метрик, CDN-скриптов и сторонних виджетов. Шрифт Inter поставляется локально (npm-пакет), поэтому
внешних запросов за шрифтами нет.

## Быстрый старт

```bash
npm install
npm run dev      # дев-сервер с hot-reload (http://localhost:5173)
npm run build    # production-сборка в dist/
npm run preview  # предпросмотр собранной версии
npm run build:offline  # сборка dist-offline/ для открытия двойным кликом (file://)
npm run images   # перегенерировать SVG-иллюстрации
npm run logo     # перегенерировать логотип ByClick (brand/)
npm run pages    # пересобрать внутренние страницы из шаблонов
```

## Страницы

| Файл | Раздел |
| --- | --- |
| `index.html` | Главная: слайдер, акции, категории, подборки |
| `catalog.html` | Каталог: фильтры, подкатегории, ползунок цены, сортировка, чипы |
| `product.html?id=…` | Карточка товара: галерея с зумом и видео, покупка, комплект, отзывы, вопросы |
| `cart.html` | Корзина: количество, промокод, итоги |
| `checkout.html` | Оформление: контакты, доставка, оплата, успех |
| `favorites.html` | Избранное |
| `login.html` | Вход и регистрация |
| `orders.html` | Мои заказы |
| `delivery.html` | Доставка и пункты выдачи |
| `help.html` | Помощь, FAQ, поддержка |
| `about.html` | О компании, контакты |
| `seller.html` | Продавцам, заявка на подключение |
| `profile.html` | Профиль: финансы, меню разделов, рекомендации |
| `404.html` | Страница ошибки |

Общие блоки (спрайт, шапка, подвал, меню, drawer, тост) живут в `index.html`, а `npm run pages`
переносит их в остальные страницы. Так шапка не расходится между разделами.

## Что работает

- **Каталог**: фильтры по категориям, цене (двойной ползунок + поля), рейтингу и доставке;
  подкатегории из мега-меню (`?sub=`), сортировка, активные чипы, счётчик, пустое состояние,
  мобильный drawer фильтров.
- **Мега-меню каталога**: слева основные категории, справа подкатегории активной категории
  (наведение, клик, клавиатура).
- **Товар**: динамическая подстановка по `?id`; миниатюры слева от большого фото, зум при наведении,
  полноэкранный просмотр, видеообзор, краткое описание, выделенный блок покупки, «Покупают вместе»
  с пересчётом суммы, отзывы с фильтрами и «Полезно», вопросы и форма вопроса, «Рекомендуем».
- **Профиль**: карточка пользователя, меню разделов (на мобильных — аккордеон), баннер сертификата,
  «Мои финансы», персональные рекомендации.
- **Корзина**: выезжающая панель и отдельная страница, количество, удаление, очистка,
  промокод `BYCLICK10`, итоги, сохранение в `localStorage`.
- **Оформление**: состав заказа, способ получения и оплаты, валидация, демо-успех с номером.
- **Избранное**: сердечки на карточках, отдельная страница, счётчик, очистка.
- **Вход/регистрация**: вкладки, валидация, демо-отправка.
- **Информационные страницы**: доставка, помощь с FAQ, о компании, продавцам, 404.
- **Поиск** с подсказками по товарам на странице, слайдер, таймер, мобильное меню.
- **Адаптив** 320 → 1920+, `safe-area-inset-bottom`, доступность (aria, `inert`, фокус, `prefers-reduced-motion`).

## Соглашения

- **BEM**, все классы с префиксом `va_` (`va_product-card__title`, `va_btn--primary`).
- CSS-переменные для токенов: цвет, радиусы, тени, анимации.
- Mobile-first, брейкпоинты `480 / 768 / 1024 / 1280`.
- JS — нативные ES-модули без фреймворка и зависимостей.
- Состояние корзины и избранного — `localStorage`; данные для страницы товара — JSON в разметке.

## Запуск в OSPanel

Собранная версия — статика в `dist/`. Укажите домен в OSPanel на папку `dist` (или на корень
проекта и запускайте `npm run dev` / `npm run preview`). Для `404.html` настройте `ErrorDocument`
в Apache, если нужна обработка несуществующих адресов.

## Почему не работает двойной клик по `dist/index.html`

Vite подключает стили и скрипты отдельными файлами с атрибутом `crossorigin`:

```html
<link rel="stylesheet" crossorigin href="./assets/style.css">
<script type="module" crossorigin src="./assets/main.js"></script>
```

При открытии через `file://` у страницы origin `null`, и Chrome блокирует такие запросы
по CORS — CSS и JS не загружаются, поэтому видна «голая» разметка без стилей и интерактива.

Варианты:

1. **Через сервер** — OSPanel/Apache на папку `dist`, либо `npm run preview`. Это основной способ.
2. **Без сервера** — выполнить `npm run build:offline`. Появится папка `dist-offline/`, в которой
   CSS и JS уже встроены в каждый HTML, а пути к шрифтам исправлены. Можно открыть
   `dist-offline/index.html` двойным кликом; переходы, корзина и избранное работают в рамках
   одного браузера.

Обычный `dist/` остаётся оптимизированным для хостинга, `dist-offline/` — только для локального
просмотра без сервера.
