# ByClick — чек-лист разработки

Живой документ. Отмечаем сделанное, возвращаемся перед каждым этапом.
Стек: Laravel 13, Livewire 4, MariaDB (`mkt_byclick`, префикс таблиц `byc_`), Vite, Pest.

## Архитектурные решения

- [x] SCSS шаблона переносим как есть (BEM + префикс `va_`), на Tailwind **не** переписываем.
- [x] JS из `.tpl` не переносим: корзина, избранное и фильтры — на Livewire + БД.
- [x] Деньги храним целыми числами в копейках, валюта BYN (`config/marketplace.php`).
- [x] Цены/статусы — PHP enum + cast, без строковых констант в коде.
- [x] `.tpl` — отдельный git-репозиторий, в корневой не входит (`.gitignore`).
- [x] Мультипродавец заложен в модель (`shops`), кабинет продавца — позже.
- [x] Auth — свои Livewire-страницы, без новых пакетов.
- [x] Админка — свой Livewire-раздел `/admin`, без Filament.
